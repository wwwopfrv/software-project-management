# SRS – Software Requirements Specification
## Система управления проектами (аналог Jira/Trello)

---

## 1. Введение

### 1.1 Цель документа
Документ описывает функциональные и нефункциональные требования к системе управления проектами.

### 1.2 Область применения
Веб-приложение для управления задачами, проектами и командами.

### 1.3 Определения и аббревиатуры
| Термин | Описание |
|--------|----------|
| SRS | Software Requirements Specification |
| CRUD | Create, Read, Update, Delete |
| API | Application Programming Interface |
| SP | Story Points (оценка сложности) |

---

## 2. Общее описание

### 2.1 Описание продукта
Система позволяет пользователям создавать проекты, управлять задачами, назначать исполнителей и отслеживать статус выполнения.

### 2.2 Пользователи системы
| Роль | Описание |
|------|----------|
| Администратор | Полный доступ, управление пользователями |
| Менеджер | Создание проектов, назначение задач |
| Исполнитель | Выполнение задач, изменение статуса |

---

## 3. Функциональные требования

| ID | Требование | Приоритет |
|----|------------|-----------|
| FR1 | Регистрация и аутентификация пользователей | High |
| FR2 | Создание/редактирование/удаление проектов | High |
| FR3 | Создание/редактирование/удаление задач | High |
| FR4 | Изменение статуса задачи (To Do → In Progress → Done) | High |
| FR5 | Назначение исполнителя на задачу | Medium |
| FR6 | Добавление комментариев к задачам | Low |
| FR7 | Фильтрация задач по проекту и статусу | Medium |
| FR8 | Дашборд с аналитикой | Medium |

---

## 4. Нефункциональные требования

| ID | Требование | Значение |
|----|------------|----------|
| NFR1 | Время отклика API | ≤ 2 секунд |
| NFR2 | Одновременные пользователи | ≥ 10 |
| NFR3 | Доступность системы | 99.5% |
| NFR4 | Технологии | Python/Flask, SQLite |
| NFR5 | Контроль версий | Git + GitHub |

## 6. План тестирования

### 6.1 Типы тестов
| Тип | Инструмент | Описание |
|-----|------------|----------|
| Модульное | pytest | Тестирование API endpoint'ов |
| Интеграционное | Postman | Проверка взаимодействия модулей |
| UI | Selenium | Тестирование интерфейса |

### 6.2 Тестовые сценарии (примеры)

| TC1 | Регистрация пользователя |
|-----|--------------------------|
| Шаги | 1. Открыть страницу регистрации<br>2. Ввести email и пароль<br>3. Нажать Register |
| Ожидаемый результат | Пользователь создан, перенаправление на логин |

| TC2 | Создание задачи |
|-----|-----------------|
| Шаги | 1. Выбрать проект<br>2. Нажать "Новая задача"<br>3. Заполнить заголовок и описание<br>4. Нажать Save |
| Ожидаемый результат | Задача появилась в списке |

|--------|--------|-----|
